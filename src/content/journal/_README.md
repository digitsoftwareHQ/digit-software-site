# Journal entries

Each public journal entry is one Markdown file in this folder, for example `autonomy-is-granted.md`:

```md
---
title: "Autonomy is granted, not assumed"
description: "One or two sentences shown on the Company page."
date: 2026-10-15
kind: Essay        # Essay | Platform | Company
draft: false       # true keeps it out of the build
---

The body, in Markdown.
```

Entries appear on /company#journal, newest first, and publish at /company/journal/<file-name>.
Only publish real writing. Do not add placeholder entries.
